# Angga Las - Body Repair & Cat Duco Landing Page

Landing page modern, bersih, profesional, dan ramah konversi untuk **Bengkel Angga Las (Bapak Wahyu Permana)** di Wanasari, Cibitung, Kabupaten Bekasi.

---

## 📁 Struktur File

```
landing-page/
├── index.html     # Halaman utama (SEO-friendly, struktur semantik)
├── style.css      # Desain sistem kustom (Clean, Industrial, Tactile 3D Buttons)
├── script.js      # Generator WhatsApp interaktif, FAQ, dan navigasi
├── gambar/        # Foto dokumentasi fisik asli bengkel
└── README.md      # Panduan cara pakai & deploy ke Netlify
```

---

## 🚀 Cara Melihat Website di Komputer / Laptop

1. Cukup buka file **`index.html`** langsung dengan mengklik dua kali (double click) dari File Explorer.
2. File akan otomatis terbuka di browser favoritmu (Chrome, Edge, Firefox, Safari).

---

## 🌐 Cara Deploy ke Netlify (Gratis Selamanya, Hanya 30 Detik!)

Agar website ini bisa diakses di internet oleh siapapun melalui link (misal: `https://angga-las-cibitung.netlify.app`), ikuti cara paling mudah ini:

1. Buka browser dan kunjungi: **[app.netlify.com/drop](https://app.netlify.com/drop)**
2. Jika belum login, kamu bisa sign up gratis dengan akun Google atau GitHub.
3. Buka File Explorer di laptopmu, arahkan ke folder:
   `d:\1-tugas-kuliah\berkas file\s7\landing-page`
4. **Drag & Drop (Tarik dan Lepas)** seluruh folder `landing-page` tersebut ke kotak bundar di halaman Netlify Drop.
5. Tunggu sekitar 5-10 detik sampai upload selesai.
6. **Selesai!** Netlify akan langsung memberikan link publik gratis.
7. *(Opsional)* Di menu **Site configuration > Change site name**, kamu bisa ganti namanya menjadi:
   `angga-las-bodyrepair.netlify.app` atau `bengkel-anggalas.netlify.app`.

## ✨ Fitur Unggulan Website

- **Desain Clean & Non-AI:** Menggunakan palet warna asli plang bengkel (Racing Red & Industrial Slate), tipografi modern Outfit + Plus Jakarta Sans, dan foto pengerjaan riil Bapak Wahyu.
- **Before & After Slider Interaktif (3 Kasus Nyata):** Pengunjung dapat memilih tab studi kasus (Avanza ringsek tabrakan depan, Kabin Truk Colt Diesel keropos bolong, dan Sedan Altis cat duco wet look) lalu menggeser slider pemisah untuk melihat hasil perbaikan presisi.
- **Rangkai Format Pertanyaan WhatsApp (Tanpa Estimasi Hari Kaku):** Calon konsumen cukup memilih jenis kendaraan, bagian rusak, dan preferensi bahan; sistem otomatis merangkai draf pesan konsultasi yang santun & rapi ke WhatsApp Pak Wahyu (**0895-3116-8549**).
- **Layout Tombol WhatsApp Rapi (Hanya 2 Titik Utama):** Bebas dari tombol WA berlebih; hanya ada di Hero banner dan tombol kirim form WhatsApp, sehingga tampilan sangat bersih dan fokus.
- **Social Proof Nyata 25+ Tahun:** Menampilkan sejarah berdirinya bengkel sejak tahun 2000 oleh Pak Wahyu Permana sebagai jaminan kualitas tangan pertama tanpa calo.
- **Google Maps Terintegrasi:** Lengkap dengan titik lokasi presisi di Wanasari Cibitung dan tombol salin alamat cepat.
- **Responsif Penuh:** Tampilan optimal di layar Smartphone, Tablet, hingga Desktop/Laptop.
